# Code Style Orchestrator — 스타일 통일화 오케스트레이터

Style Keeper의 전체 워크플로우를 조율하는 오케스트레이터.

## Phase 0: 린트/프리티어 선행 질문
분석 전 린트+프리티어 포맷팅 실행 여부를 사용자에게 묻는다.

## Phase 1: 병렬 스타일 마이닝 (팬아웃)
4개 Miner(함수/타입/컴포넌트/에러)를 동시 실행.

## Phase 2: 변종 분류 및 통계 (팬인)
결과를 통합 분류하고 우선순위 산정.

## Phase 3: 사용자 스타일 질문 (순차)
카테고리별로 하나씩 사용자에게 질문.

## Phase 4: 일괄 적용 및 검증 (순차)
AST-grep 기반 변환 + LSP 검증.

## Phase 5: 최종 정리
변경 보고서 생성, 포맷팅 재실행 옵션.
